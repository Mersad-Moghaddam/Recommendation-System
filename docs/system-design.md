# طراحی سامانهٔ سینمچ

## مرز عمومی و شخصی

جست‌وجو، جزئیات و فیلم‌های مشابه برای مهمان قابل استفاده‌اند. پیشنهاد هوشمند، امتیازدهی، onboarding و پیشنهادهای شخصی به نشست معتبر نیاز دارند. FastAPI تمام APIها را زیر `/api` و build فرانت را از همان origin سرو می‌کند؛ `/health` بیرون این prefix باقی می‌ماند.

```text
مرورگر/PWA
  ├─ GET عمومی → FastAPI → SQLite + FTS5
  └─ درخواست شخصی + HttpOnly cookie
                     ↓
              پروفایل زندهٔ کاربر
                     ↓
      artifact نسخه‌دار → Hybrid scorer → MMR
```

نشست امضاشده در cookie با `HttpOnly`، `SameSite=Strict` و `Path=/` قرار می‌گیرد و در production فقط با HTTPS (`Secure`) ارسال می‌شود. درخواست تغییردهنده علاوه بر cookie باید Origin مجاز داشته باشد. هیچ credential در `localStorage` ذخیره نمی‌شود.

## داده و جست‌وجو

`movie_metadata` با هر فیلم رابطهٔ یک‌به‌یک دارد و شناسه‌های TMDB/IMDb، خلاصهٔ فارسی و انگلیسی، کلیدواژه، زبان، کشور، مدت، منبع و زمان به‌روزرسانی را نگه می‌دارد. رکوردهای فیلم، کاربر و امتیاز پیشین دست‌نخورده می‌مانند.

`expand_movie_catalog.py` فایل‌های رسمی MovieLens 32M را با checksum ثابت کنترل می‌کند. `enrich_movie_metadata.py` با checkpoint در خود دیتابیس، fallback زبان، retry نمایی و upsert دسته‌ای metadata را از TMDB می‌گیرد. فایل `data/metadata_overrides.json` اصلاحات دستی و قابل بازبینی را اعمال می‌کند.

FTS5 عنوان نرمال‌شده، خلاصه و ژانر را ایندکس می‌کند. ی/ي، ک/ك، اعداد فارسی/عربی و اعراب پیش از indexing و query یکسان می‌شوند. بازسازی index نسخه‌دار و idempotent است.

## ساخت مدل

artifact شامل داده و ماتریس‌های لازم است و تنها در startup بارگذاری می‌شود:

1. ماتریس کاربر–فیلم با میانگین کاربر centered می‌شود و biasهای regularized کاربر و فیلم محاسبه می‌شوند.
2. `TruncatedSVD` با حداکثر ۶۴ مؤلفه و seed ثابت سیگنال نهفته را می‌آموزد.
3. TF–IDF وزن‌دار از خلاصه، کلیدواژه، ژانر، زبان، کشور و دهه ساخته می‌شود.
4. نمایهٔ محتوایی امتیازهای مثبت را اضافه و امتیازهای منفی را کم می‌کند.
5. کیفیت عمومی با میانگین بیزی محاسبه می‌شود.

وزن محتوایی/نهفته/کیفیت به‌ترتیب برای ۱–۲ امتیاز `70/15/15`، برای ۳–۹ امتیاز `50/35/15` و برای ۱۰+ امتیاز `35/55/10` است. امتیاز تازه فقط نمایهٔ همان کاربر را در زمان درخواست تغییر می‌دهد.

برای هر پاسخ، صد نامزد برتر با MMR بازچینی می‌شوند. relevance در حالت «آشنا و مطمئن» ۰٫۹۰، «متعادل» ۰٫۸۵ و «کشف تازه» ۰٫۶۵ است. دلیل پیشنهاد از قوی‌ترین سیگنال واقعی—حس، ژانر محبوب یا فیلم پسندیده‌شده—ساخته می‌شود.

## شروع سرد و onboarding

کاربر تازه دوازده فیلم متنوع می‌بیند و می‌تواند سه مورد را امتیاز دهد یا مرحله را رد کند. فرم حس‌وحال دوازده گزینه دارد؛ حداکثر دو حس پذیرفته می‌شود و «غافلگیرم کن» انحصاری است. نبود metadata پنهان نمی‌شود و خلاصهٔ انگلیسی با `lang=en` و `dir=ltr` تحویل می‌شود.

## PWA و cache

React routeها lazy هستند، GETهای عمومی در حال پرواز deduplicate می‌شوند و جست‌وجو abortable است. service worker فقط shell، assetهای hash‌شده، فونت و تعداد محدودی GET عمومی اخیر را نگه می‌دارد. مسیرهای `/api/auth`، `/api/ratings`، `/api/users` و `/api/recommendations` در هیچ runtime cache قرار نمی‌گیرند.

## رفتار production

در توسعه، نبود artifact باعث یک build هنگام startup می‌شود. در production، نبود یا قدیمی‌بودن artifact با پیام setup متوقف می‌شود تا request نخست هزینهٔ آموزش نپردازد. SQLite برای پروژهٔ دانشگاهی و اجرای تک‌نمونه‌ای انتخاب شده؛ استقرار چندنویسنده‌ای به پایگاه داده و session store مستقل نیاز دارد.
